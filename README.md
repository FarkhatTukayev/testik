## Скрипт для прокрутки списка в Dota 2 до даты

Теперь это **desktop-автоматизация для игры**, а не браузера.

Файл: `scroll_until_date_dota2.py`

Что делает скрипт:
1. Делает OCR текста на экране (или в заданном регионе).
2. Если видит `Load more` — кликает по надписи.
3. Крутит колесо мыши вниз.
4. Повторяет, пока не найдёт дату (по умолчанию `13/4/2025`).

## Требования

```bash
pip install pyautogui pytesseract pillow
```

Также должен быть установлен **Tesseract OCR** в системе.

## Важно

- Перед запуском откройте Dota 2 и перейдите в нужный список.
- Во время работы скрипт управляет мышью.
- Для аварийной остановки используйте fail-safe PyAutoGUI: резко уведите курсор в левый верхний угол экрана.

## Быстрый запуск

```bash
python3 scroll_until_date_dota2.py
```

## Рекомендуемый запуск с регионом списка

```bash
python3 scroll_until_date_dota2.py \
  --list-region "500,220,900,760" \
  --ocr-region "500,220,900,760" \
  --target-date "13/4/2025" \
  --load-more-text "Load more"
```

Где регион задаётся как: `x,y,width,height`.

## Параметры

- `--target-date` — целевая дата `d/m/yyyy`.
- `--load-more-text` — текст кнопки догрузки.
- `--list-region` — регион, в который отправлять скролл.
- `--ocr-region` — регион для OCR (если не задан, берётся `list-region`, иначе весь экран).
- `--max-steps` — максимум шагов прокрутки.
- `--scroll-amount` — сила одного скролла.
- `--pause-s` — пауза между шагами.
- `--lang` — язык OCR (например `eng`).
- `--startup-delay-s` — задержка перед стартом, чтобы успеть переключиться в игру.
