## Скрипт для прокрутки списка до даты

`scroll_until_date_playwright.py` делает следующее:

1. Прокручивает список колёсиком мыши.
2. Если встречает надпись `Load more` — кликает по ней.
3. Продолжает прокрутку, пока не увидит целевую дату (по умолчанию `13/4/2025`).

### Что улучшено

- Поиск даты поддерживает разделители `/`, `.` и `-` (например: `13/4/2025`, `13.04.2025`, `13-4-2025`).
- Для контейнера со списком применяется двойная прокрутка: wheel + изменение `scrollTop` как fallback.
- Добавлена защита от «зависания»: если список долго не меняется и `Load more` не нажимается, скрипт завершится с понятной ошибкой.

### Запуск

```bash
python3 scroll_until_date_playwright.py \
  --url "https://example.com/list" \
  --list-selector ".list-container"
```

Если скроллится вся страница, `--list-selector` можно не передавать.

### Полезные параметры

- `--target-date "13/4/2025"` — целевая дата.
- `--load-more-text "Load more"` — текст кнопки подгрузки.
- `--max-scrolls 800` — максимальное число прокруток.
- `--scroll-pixels 1200` — размер шага прокрутки.
- `--pause-ms 500` — пауза между действиями.
- `--stagnant-limit 25` — лимит шагов без прогресса перед остановкой.
- `--headless` — запуск без окна браузера.
